# Informationen zu Lied von KI #

<br>

Dieses Repository enthält ein Java-TextUI-Programm in der Form eines Maven-Projekts.
Das Programm fragt einen Interpreten (Einzelkünstler oder Band) und den Titel eines
Lieds ab, und ruft dann dazu Informationen von einer KI/LLM über
[OpenRouter.ai](https://openrouter.ai/) ab.
Für den Zugriff auf *OpenRouter* wird die Bibliothek
[Simple-OpenAI](https://github.com/sashirestela/simple-openai)
verwendet.

<br>

Für die Ausführung des Programm muss in der Umgebungsvariable `OPENROUTER_API_KEY`
ein API-Key von openrouter.ai enthalten sein.

<br>

JavaDoc-Dokumentation wird mit *GitHub Pages* unter der folgenden URL bereitgestellt:

https://mdecker-mobilecomputing.github.io/Maven_LiedDetailsVonKI/
